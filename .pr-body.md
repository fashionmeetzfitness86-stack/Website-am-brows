# Admin Dashboard v2 — Full Feature Release

## Summary
This PR delivers the complete Admin Dashboard upgrade for Ashley M. Brows, covering staff management, booking review, document printing, client photo display, and a real-time notification system.

---

## ✅ Features Included

### 📋 Booking Management
- **Clickable booking rows** — click any row to open a full slide-over review panel
- **Edit confirmed date/time** — approve requested time or set a custom one
- **Send confirmation email** — triggers `send-confirmation-email` Edge Function
- **Admin notes** — private internal notes saved per booking
- **Cancel & 2-step delete** — cancel request or permanently delete with confirmation

### 🖨️ Print / Document View
- **"View / Print Document"** button in the booking modal opens a clean intake document at `/admin/print/:id`
- Fully formatted **8.5×11 intake form** with:
  - Client info, service, requested/confirmed date
  - Health conditions, previous PMU, skin type, client notes
  - **Client photo thumbnails** (current brows + reference goal) via signed Supabase Storage URLs
  - Admin/studio notes section
  - Artist, client, and date signature lines
- **Print / Save PDF** button hides UI chrome for a clean printout

### 📸 Client Photos in Modal
- Photos submitted at booking time now display **inline inside the slide-over modal**
- Uses Supabase Storage signed URLs (1-hour expiry) for the private `booking-photos` bucket
- Graceful loading spinner + "Unavailable" fallback

### 👥 Staff Management (Team Tab — Super Admin Only)
- **Create staff account directly** — admin sets full name, email, and password; staff can log in at `/login` immediately via `create-staff-user` Edge Function
- **Edit member panel** — change name, email, role (`staff` ↔ `super_admin`), and reset password
- **Remove staff** — deletes the `user_roles` row instantly
- All destructive actions require a 2-step browser confirmation

### 🔔 Notification System
- **Bell icon in header** with live **unread count badge**
- **Real-time updates** via Supabase Realtime — notifications appear instantly without refresh
- **Notification dropdown panel** — shows title, body, timestamp, dismiss `×` per item, "Clear all"
- **Email Alerts toggle per staff member** in the Team table (toggle switch)
  - Super Admin: always receives email alerts (toggle locked On)
  - Staff: Off by default — Super Admin can flip the toggle to enable
- **`notify-new-booking` Edge Function** — fires on new booking insert via DB Webhook, sends branded email to all recipients and writes in-app notification rows

### 🆕 New Edge Functions
| Function | Purpose |
|---|---|
| `update-staff-user` | Update auth user email, password, and role via service_role |
| `notify-new-booking` | Email + in-app notification on new booking insert |

## 🗄️ Required Database Migrations

Run in Supabase SQL Editor before deploying:

```sql
-- Notification preferences per user
alter table public.user_roles
  add column if not exists email_notifications boolean default false;

-- In-app notifications table
create table if not exists public.notifications (
  id uuid default gen_random_uuid() primary key,
  created_at timestamp with time zone default timezone('utc'::text, now()) not null,
  user_id uuid not null references auth.users(id) on delete cascade,
  type text not null default 'new_booking',
  title text not null,
  body text,
  booking_id uuid references public.bookings(id) on delete set null,
  read boolean default false
);
alter table public.notifications enable row level security;
create policy "Users manage own notifications"
  on public.notifications for all using (auth.uid() = user_id);

-- Staff invites table (for future invite-link flow)
create table if not exists public.staff_invites (
  email text primary key,
  role text not null default 'staff',
  created_at timestamp with time zone default timezone('utc'::text, now()) not null
);
alter table public.staff_invites enable row level security;
create policy "Super admins manage invites"
  on public.staff_invites for all
  using (exists (select 1 from public.user_roles where user_id = auth.uid() and role = 'super_admin'));
create policy "Anyone can read invites"
  on public.staff_invites for select using (true);
```
