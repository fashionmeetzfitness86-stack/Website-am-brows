## Summary

## Bug Fixes

- **Dead code removed** — unused `stripePromise`/`loadStripe` import and Formspree endpoint constants deleted

- **Mobile CTA guard** — sticky 'Book Now' bar hidden on `/booking`, `/booking/success`, and `/booking/cancelled`

## Features Added

### SEO + Performance
- `src/hooks/useSEO.ts` — updates `document.title`, meta description, og tags, and canonical URL on every route change (9 routes)
- `schema.org BeautySalon` JSON-LD injected on mount with full service catalog, geo coords, pricing, and social links
- `loading=lazy` + `decoding=async` on all gallery and Instagram feed images

### Admin Dashboard
- Live search across client name, email, service, date
- Filter pills: Status (All / Confirmed / Pending Deposit / Cancelled) and Deposit (All / Paid / Unpaid)
- Skeleton loading rows while data fetches
- Context-aware empty states
- Rich status badge colors: emerald, amber, red, blue
- Refresh Data button with spinner indicator
- Received date column on both tables

### Role-Based Access Control
- `user_roles` table with `super_admin` and `staff` roles
- Dashboard reads role on login and shows Team tab only to super_admin
- **Team tab**: invite staff by name + email + temp password, list all members, remove staff users
- Super_admin cannot be removed via UI

### New Edge Function
- `supabase/functions/create-staff-user/index.ts` — server-side user creation; validates caller is `super_admin` before acting; uses `service_role` key only in Edge Function

### Documentation
- `PRELAUNCH.md` — 11-section pre-launch checklist
- `supabase/schema.sql` — updated with `user_roles` table, RLS policies, indexes
- `.env.example` — updated with all 3 required frontend vars
